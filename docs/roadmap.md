# Learning Approach

The lab follows a progressive approach.

Each capability should be introduced when the underlying engineering problem becomes relevant.

For example:

```text
Conversation History
        ↓
Context grows
        ↓
Context limits become relevant
        ↓
Memory
```

And:

```text
Need external knowledge
        ↓
Embeddings
        ↓
Retrieval
        ↓
RAG
```

And:

```text
Need to interact with external systems
        ↓
Tool Calling
        ↓
Agents
```

The goal is to understand the problem first and then introduce the appropriate AI Engineering pattern.
